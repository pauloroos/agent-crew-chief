# Tutorials

These tutorials use the small [`examples/hello-crew/`](../../examples/hello-crew/) project.

1. [Your first job in 10 minutes](01-first-job.md) — install ACC, dispatch a small change to a free executor, review it, and close the job.
2. [Spec-driven work](02-spec-driven.md) — turn a multi-requirement feature into tasks with acceptance criteria and proof.
3. [Cost and safety](03-cost-and-safety.md) — understand tiers, budgets, sensitive paths, and safe delegation.
4. [The maestro](04-maestro.md) — let your agent split a goal into fronts, run one coordinator per front with automatic fallback, and hand you one PR per front with its rounds, time, tokens and score.
