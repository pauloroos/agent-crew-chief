# Hello Crew

Este é um projeto pequeno para praticar os tutoriais do agent-crew-chief. Ele não tem dependências de execução. Nos tutoriais, você vai adicionar e testar uma função simples com o ACC.

## Copie para usar no tutorial

Copie esta pasta para um lugar novo e entre na cópia:

```bash
cp -R examples/hello-crew ~/projects/hello-crew
cd ~/projects/hello-crew
git init
git add .
git commit -m "Start hello-crew practice project"
```

Rode os testes com `pytest`. O pacote usa a estrutura `src/`, então os comandos do tutorial instalam o ACC neste repositório Git antes de criar os jobs.
