# Hello Crew

O projeto de exemplo do tutorial do agent-crew-chief (ACC). Siga `docs/tutorial.pt-BR.md` no repositório do ACC.

Copie esta pasta para fora do checkout do ACC e transforme-a num repositório Git próprio antes de usar:

```bash
cp -R examples/hello-crew ~/projects/hello-crew && cd ~/projects/hello-crew
git init && git add . && git commit -m "Start hello-crew"
python -m pytest -q
```
